# AE2020 人工验收清单

目标：Windows 64 位 Adobe After Effects 2020（17.x）中的 CEP 面板。每一行只在现场直接观察后填写“通过”或“失败”；没有执行就填写“未验证”，不要根据 Node 测试或 Chrome 截图推断通过。

记录日期：____  AE 版本：____  项目副本/临时项目：____  操作者：____

## 前置条件

1. 使用一个可丢弃的 AE 项目副本，至少导入三个文件素材：普通图片或视频、一个图片序列、一个将被改名或路径缺失的素材。记录项目项名称和路径。
2. 面板安装和开发配置由操作者按本机流程完成；本项目不自动安装扩展、不写注册表、不启用调试标志。
3. 验收前记录项目文件、素材文件和文件夹状态。验收后重新检查，确认面板没有写入项目或素材。

## 证据边界

- Node 测试：Task 5 基线覆盖 54 项；加入 Task 6 校验器夹具后最终覆盖 71 项，包括 host JSON/选择、搜索、路径动作、UI 状态和扩展引用校验；不等于 AE2020 实机通过。
- `npm.cmd run validate`：验证 11 个仓库内资源、manifest 目标和引用闭包；不等于 CEP 加载通过。
- Chrome 静态检查：复用 Task 5 的真实 `cep/index.html` 结果页截图/Range 选择证据；不证明 Chromium 61、CEP 剪贴板或 Explorer 行为。
- AE 探针：曾用子进程环境令牌和 `-m -r` 尝试只读启动，25 秒内未生成令牌验证文件；未创建、导入、保存或修改项目，因此 AE JSX/CEP 实机行为仍未验证。
